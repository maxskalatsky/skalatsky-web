Equinix Software Diagnostic

The interconnection software portfolio, the open weight demand thesis, and what the platform looks like from outside it.

August 2, 2026  ·  Internal working document

1. What the software business is

Equinix is a REIT that owns 280 data centers across 77 metros. The software exists to make that footprint programmable and to keep customers from needing to leave it.

  • FabricVirtual interconnection. Buy a port, spin circuits to clouds, networks, and SaaS in minutes. Over 4,400 customers.
  • Fabric Cloud RouterVirtual routing instance. Reach several destinations at Layer 3 with no hardware in the cage.
  • Network EdgeVirtual network functions from Palo Alto, Fortinet, Cisco, deployed in minutes instead of shipped to a cage.
  • Fabric IntelligenceLaunched April 2026. Super Agent, MCP server, Application Connect marketplace, Fabric Insights telemetry.
  • MetalSunset June 30, 2026. Read as discipline: they exited undifferentiated compute and funded the layer where the footprint is the moat.
The number that matters

2025 revenue $9.217B, adjusted EBITDA margin 49%, 2026 outlook above $10.1B with margin to 51%. Q2 2026: recurring revenue up 11%, margin up 300 basis points to 53%, a record 9,700 net interconnections. Inside that, Fabric revenue grew 26% with bookings up 70% against 9% interconnection growth overall. Software is the growth story on a slower asset base, and it carries the best margin in the stack. Neither Fabric nor Network Edge is broken out as a line item, so any dollar figure attributed to either is someone's estimate.

3. How the open weight wave drives demand

Four AI demand patterns were named on the Q2 call: private AI stacks to cut token costs, sovereign deployments for residency, AI factory batch inference with liquid cooling, and latency sensitive metro inference. Three of those four are the open weight transition described in enterprise language.

The mechanism

  • Self hosting became rational. Once a capable open weight model sits within a couple of points of the frontier, the enterprise question stops being which model and becomes where it runs and who controls the data path.
  • Cost per task, not per token. Artificial Analysis, July 2026: $0.03 per Intelligence Index task for DeepSeek V4 Flash against $3.15 for Fable 5, roughly 105 times cheaper. On Terminal Bench 2.1 the capability gap is inside the noise at 82.7 versus 80.5.
  • Agentic traffic is bursty and machine to machine. Dynamic bandwidth between fixed endpoints is the exact shape of a Fabric connection.
  • Inference sprawls where training concentrates. Training sits in a few campuses. Inference follows users and data, which re rates a footprint of 77 metros.

Two tensions to carry, not paper over. The pricing above is metered API pricing on someone else's hardware, so on its own it argues for renting open weight inference rather than self hosting it. The self hosting case rests on residency, egress, latency to private data, and control of the artifact. And cheap inference is deflationary per workload: the win is many more inference endpoints in many more places, not higher spend per customer.

4. Where the software can go

With a monetization path
  • A metered control plane. Fabric Intelligence is a feature today; per seat or per action pricing makes it a software line on top of circuit revenue.
  • Marketplace economics on Fabric Application Connect, with 2,000 plus AI ecosystem partners already on the supply side.
  • Cost attribution for AI traffic, extending Fabric Insights into the FinOps conversation where AI budget authority sits.
  • Security service insertion. Prisma AIRS on Network Edge is the template for every vendor that needs to sit in the path of agent traffic.
  • Sovereign inference bundles: compute, interconnection, jurisdiction, and policy sold as one contract.
Without one, correctly
  • The Terraform provider and published modules. Pure adoption infrastructure, so an engineer can standardize without a procurement conversation.
  • Playground and the developer platform. A funnel, not a product.
  • Documentation and OpenAPI quality. Underrated: every hour of friction is a circuit bought somewhere else.
The structural test

A harness makes the layer beneath it substitutable. Terraform did exactly that to clouds. Software that is only valuable because of where it runs does the opposite. Application Connect is the right shape, because a private path to inference capacity is worth more from a building that contains the capacity. A generic control plane for distributed AI infrastructure is the wrong shape, because it works equally well pointed at someone else's footprint. If the software would work just as well against a competitor's facility, it makes Equinix more replaceable, not less.

6. Field notes from the platform

Everything above is research. This section is four hours with the platform and its closest competitor.

The build

Mocked the Fabric v4 API locally and ran Equinix's own Terraform provider against it, unmodified from the public registry, version 5.1.0. Full cycle clean: apply created a Cloud Router and an IP_VC connection to a service profile, a second plan reported no changes, destroy tore down connection then router in dependency order. A small dashboard over the same mock showed state transitions and every call underneath.

Four provider rejections, and they are the only new technical knowledge from the day. The OAuth response does not follow RFC 6749: it wants token_timeout and user_name rather than expires_in, and those timeouts must be JSON strings rather than numbers. Service profile access point configs are a strict discriminated union. The wait target is PROVISIONED, not ACTIVE.

The sharpest thing the build surfaced

Terraform cannot function without delete on routers and connections. The Fabric MCP server does not support delete for routers, ports, or connections, and the documentation recommends human confirmation on anything that creates or updates. Same company, two automation interfaces, opposite answers on the most dangerous operation. That is the trust ceiling for agentic network operations, stated by the product itself.

Caveat The mock echoes back what the provider sends, so a clean second plan proves the loop and the state machine, not that field names match production. VLAN placement was a guess, since neither end of a router to profile connection is a port.

The portal

  • Quick Connect preselects Redundant as the only connection type offered, roughly doubling recurring cost, and says nothing about that on screen. The same step asks for a customer BGP ASN, so a wizard built to make interconnection approachable still assumes the buyer knows what an autonomous system number is.
  • Ordering vocabulary is everywhere: Submit Order, purchase order number required, term commitments, early termination fees. This is a procurement flow wearing a console's clothes.
  • The marketplace is partly catalog and partly directory. Groq, Zenlayer, Iterate, and Deutsche Telekom carry Connect buttons; Infercom, Vultr, DigitalOcean, Cirries, Argyll, Cloudera, and Outscale offer only View details. A buyer cannot tell which is which without clicking.
  • Equinix lists itself as a service provider in its own marketplace. Defensible, and worth asking about given that neutrality is the stated differentiator.
  • AI Sovereign appears as a tag across Infercom, Argyll, and Outscale. The sovereignty demand pattern named on the Q2 call has become an actual taxonomy in the product four months later. That is the strongest outside evidence the strategy is more than narration.

The comparison, and two corrections

Correction one. Sales led onboarding is how the category works, not an Equinix failing. Megaport also gates signup behind a demo. Interconnection allocates physical resources and bills for them, and none of these companies are built for a stranger to swipe a card.

Correction two, running the other way. Equinix's developer surface is deeper, not shallower. Developer Tools carries Go, Java, and Python SDKs, the Terraform provider, a Pulumi provider, Terraform modules, an API notification center, a messaging gateway, and an entry for Fabric MCP Servers. Megaport has an API key generator and webhooks.

Megaport, once inside

Staging environment mirrors production, deploys nothing, bills nothing, resets every 24 hours. Self serve API key generator and webhooks in the portal navigation. Release notes show active integrators: webhooks in April, cloud router ping and traceroute in May, flow export in June, telemetry in July, with dated deprecation windows throughout.

One item stands out. In May 2025 they added a safe delete parameter specifically because deleting a product through their Terraform provider could silently take attached circuits with it. That is a company thinking about how its API behaves under an automation client.

Equinix, once inside

Trial states plainly that API and Terraform are unavailable. Playground returns static data. Sandbox requires customer status. The MCP server is private beta behind an account representative.

Net: I built my own sandbox because the competitor gives one away.

So the gap is access, not tooling. Equinix publishes more and gates the credential. Megaport publishes less and hands it over immediately. Which posture is right depends entirely on whether the buyer for Fabric Intelligence is a procurement led network team or a platform engineer. That is a question for the product organization, not one to answer from outside.

7. Open questions

  • Preview stage products do not move revenue for several quarters. How much patience does the P&L have for a control plane bet inside a REIT that just raised guidance twice?
  • Power availability, not demand, is the binding constraint on the core business. Which parts of the software portfolio can accelerate independently of physical capacity, and which only appear to be slow?
  • Metal proves Equinix will exit a software business that does not compound with the footprint. Any adjacency has to answer why it strengthens interconnection rather than diversifying away from it.
  • Does the market ever get to price this as software? That requires breaking out the line, and a separately reported number can also disappoint separately.
